Retrouve ici les commandes disponibles sur Discord et la manière de les utiliser avec l'overlay.

!livechat Afficher un média

Envoie une image ou une vidéo Discord dans la file d'attente du LiveChat. Tu peux ajouter un message sous le média.

  1. Écris !livechat dans le salon Discord configuré.
  2. Ajoute un seul média autorisé en pièce jointe.
  3. Ajoute du texte après la commande si tu le souhaites.
  4. Envoie le message : l'overlay s'occupe du reste.
Exemple avec une pièce jointe : !livechat Voici mon message
!stop Arrêter l'affichage

Interrompt immédiatement le LiveChat actuellement visible. Le message arrêté est marqué comme consommé et la file peut continuer.

  1. Attends qu'une image ou une vidéo soit affichée.
  2. Écris !stop dans le salon Discord configuré.
  3. L'overlay masque le média et le bot répond « LiveChat Stoppé ».
!next Passer au suivant

Interrompt le média visible et lance immédiatement le prochain LiveChat présent dans la file d'attente.

Commande : !next
!pause Mettre en pause

Empêche le démarrage des prochains LiveChats. Le média déjà visible termine normalement son affichage.

Commande : !pause
!resume Reprendre

Réactive l'affichage après une pause. Les messages en attente reprennent dans leur ordre d'arrivée.

Commande : !resume
!clear Vider la file

Arrête le média actuel et retire tous les LiveChats encore en attente pour l'ensemble des applications.

Attention, cette action concerne toute la file : !clear
!status Voir l'état

Indique si le LiveChat est actif ou en pause, le nombre d'applications actives et le nombre de messages en attente.

Commande : !status
!ping Tester le bot

Vérifie rapidement que le bot Discord est bien démarré et qu'il reçoit les commandes dans le salon configuré.

Commande : !ping
À savoir
  • Les commandes fonctionnent uniquement dans le salon Discord configuré.
  • Les liens YouTube ne sont pas acceptés : il faut joindre le fichier.
  • Formats acceptés : JPG, PNG, GIF, WebP, AVIF, MP4, WebM, MOV et M4V.
  • Limites : 10 Mo par image et 25 Mo par vidéo.
  • Chaque utilisateur doit attendre 20 secondes entre deux LiveChats.
  • La pause n'interrompt pas le média déjà visible.
  • !clear vide la file pour toutes les applications.
  • Une image reste affichée 15 secondes.
  • Une vidéo utilise sa durée réelle, avec une limite de 60 secondes.
